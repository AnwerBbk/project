# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple application that calculates the interest earned or paid on a principal amount over a specific period of time.

## Formula

Simple Interest is calculated using the following formula:

**SI = (P × R × T) / 100**

Where:
- P = Principal amount
- R = Annual interest rate (percentage)
- T = Time period (in years)
- SI = Simple Interest

## Example

If:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

SI = (1000 × 5 × 2) / 100 = 100

The total amount is:

Total Amount = Principal + Simple Interest = 1100

## Features

- Calculate simple interest.
- Display the total amount.
- Easy to use.
- Simple and clear calculation process.
